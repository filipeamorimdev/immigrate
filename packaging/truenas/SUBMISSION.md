### Special Notes

- The Photos library storage must be a dataset, such as `/mnt/tank/photos`. It's
  always mounted read-only at `/nas`, and the permissions step never runs on it.
  You choose the library inside it in the web UI.
- The user and group must be able to read the library.
- The Immich URL and API key are optional in the form. They can be entered in the
  web UI instead. The API key is stored in the data storage and never sent to the
  browser.
- The root filesystem is read-only, with a tmpfs at `/run`. Temporary copies of
  the Photos database go to `/data/tmp`.
